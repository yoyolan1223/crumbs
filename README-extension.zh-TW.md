# 麵包屑 Crumbs 🐦

> 給分心大腦的小麻雀。你在分頁之間跳來跳去，啾啾跟在後面，一粒一粒把麵包屑撿起來。

Chrome 擴充功能（Manifest V3），不需要帳號、不連任何伺服器，所有資料只存在你自己的瀏覽器裡。

## 它會做什麼

| 功能 | 說明 |
|---|---|
| **自動足跡** | 記錄你切換分頁／視窗的順序、每頁停了多久。只閃過不到 1.5 秒的分頁不算一步。離開 Chrome 時暫停計時。 |
| **每頁的主旨** | 從網址和標題判斷你在做什麼：`處理信件`、`寫文件`、`做簡報`、`搜尋「…」`、`寫程式`、`滑社群`……（規則在 `shared.js` 的 `RULES`） |
| **上一步提醒** | 網頁右側有一隻探頭的小麻雀（可上下拖曳），點它就下拉足跡：「剛剛你在：做簡報 · 募資簡報 v3（12 分）」、寫「這頁要做什麼」、點足跡跳回去、按 ✕ 刪掉。預設不自動跳出，想要的話在側欄打開。 |
| **接下來做什麼** | 側欄會把足跡整理成待辦，依照「做到一半的」「花最多時間的」「一直回來看的」「工作 > 娛樂」排出順序，並告訴你**為什麼**。 |
| **打勾、完成度** | 每件事都有 25／50／75／100% 四格進度條，點一下就能更新；也可以打勾、釘選、隱藏，或手動加一件事。 |
| **一週回顧** | 側欄「📊 一週」打開。每天花在哪些專案的長條圖、各專案時數和跟上週比較、還沒分類的分頁一鍵歸類、做事類型分布。專案用關鍵字自動歸類（例：`募資, deck`），也能在側欄每件事的「＋ 專案」手動指定。資料保留 60 天。 |
| **刪除** | 側欄每件事、每個足跡右邊有半透明 ✕；下拉選單裡也有。 |
| **麵包屑罐** | 點右上角的小罐子（或「罐子」分頁）。完成事情、進度往前、從滑手機回到正事、專心 25 分鐘，都會掉麵包屑進罐子；每天裝滿 24 粒，多的會堆到蓋子上。還有連續天數和最近 7 天的小罐子。**分心不會扣分，罐子只會越來越滿。** |
| **啾啾** | 會依照你的狀態換表情和台詞：10 分鐘內換太多分頁會暈、完成一件事會得意、清單空了會叫你去喝水。 |

## 安裝（開發者模式，約 1 分鐘）

1. 打開 Chrome，網址列輸入 `chrome://extensions`
2. 右上角打開 **開發人員模式**
3. 點 **載入未封裝項目**，選這個 repo 的資料夾
4. 把工具列上的小麻雀釘選起來，點它就會打開側欄

### 快捷鍵

- `⌥ ⇧ C`：打開側欄
- `⌥ ⇧ Z`：我剛剛在幹嘛？（在目前頁面彈出足跡）

可以在 `chrome://extensions/shortcuts` 修改。

## 不用安裝，先看畫面

```bash
python3 -m http.server 4610   # 在 repo 資料夾裡執行
```

然後打開 <http://localhost:4610/dev/preview.html>，裡面有一整個早上的假資料；點上方的假分頁，就能看到小卡掉下來、側欄即時更新。

## 檔案

```
manifest.json     擴充功能設定
background.js     service worker：監聽分頁／視窗事件、寫入 storage
shared.js         純邏輯：網址 → 主旨、排序、啾啾 SVG（三個環境共用）
content.js        頁面上的「剛剛你在…」小卡（Shadow DOM，不會被網站樣式污染）
sidepanel.*       側欄 UI
dev/              假 chrome API + 預覽頁，只給開發用
icons/            由 icons/sparrow.svg 產生
```

## 隱私

- 需要的權限：`tabs`（讀分頁網址／標題）、`storage`、`sidePanel`、`scripting`（安裝時補注入到已開的分頁）、`favicon`
- 不讀網頁內容、不上傳任何東西。資料保留 48 小時，按「清空重來」立即刪除。
